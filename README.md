## Команды
- 'npm install'
- 'npm run dev'
- 'npm run build'
- 'npm run deploy'

Проект разворачивается c помощью Vite

## Сборка и публикация
- 'npm run build' - создает сборку в папке 'dist'
- 'npm run deploy' — публикует собранный проект на GitHub Pages
